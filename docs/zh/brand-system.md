为 DFC Bridge 产品命名，或为网站、图解和发布材料选择标志时，使用本页。保持公开品牌一致，不要因此改动交付契约中的稳定标识符。

## 名称

- 首次解释时使用 **DFC Bridge — Design Frontend Contract**，之后简称 **DFC Bridge**。
- 口头简称是 **Bridge**（俄语 **Бридж**），不要求团队在交谈时逐字母读出缩写。
- 产品名称为 **DFC Bridge Assistant**、**DFC Bridge Explorer**；技术标识为 `dfc-bridge`、`dfc-bridge-*`。
- 保留 Bridge 六项原则与现有 B 图形；品牌更名改变文字标志，不改变方法论。
- `bridge`、`bridgeKey`、`[bridge-exception=…]`、模式 ID 和已发布的数据地址都是稳定契约标识，不是另一套品牌名称。
- 历史版本保留原名。协调完成外部迁移前，保留可用的仓库和 Pages 地址；仓库重定向不等于 Pages 网站重定向。

## 含义

图形由六个有序模块组成，英文首字母构成 BRIDGE：

1. **B — Breakpoints：** 响应式断点；
2. **R — Roles：** 图层职责；
3. **I — Identity：** 稳定标识；
4. **D — Dependencies：** 依赖与关联；
5. **G — Geometry：** 可复现的几何；
6. **E — Exceptions：** 有意声明的例外。

模块以一致节奏交替排列实心结构和开放部分，共同构成抽象的 **B**：一个由明确部件组成、在不同尺寸下仍可辨认的整体。

标志有意不画实体桥梁。DFC Bridge 描述的是设计交付契约，因此图形表达稳定结构与连续性，而不是某个地点或物体。

<a id="调色板"></a>

## 配色

| 令牌 | 色值 | 含义 |
| --- | --- | --- |
| DFC Bridge Ink | `#1E1E1E` | 结构、技术准确性、主要文字标志 |
| DFC Bridge Blue | `#0D99FF` | 明确的意图、进行中的交付路径 |
| White | `#FFFFFF` | 对比与留白 |

主标志只使用这三色。错误、警告和草稿等产品状态色属于界面语义，不加入标志。

## 规则

- 显示条件允许时使用完整彩色标志。
- 印章、小型技术图解或受限印制场景使用单色标志。
- 安全留白至少等于一个内部模块间距。
- 图形最小为 `16 × 16 px`；图文组合标志最小宽度为 `120 px`。
- 保留模块顺序、间距、圆角几何及蓝白交替节奏。
- 不添加渐变、阴影、描边、额外文字或实体桥拱。
- 不把六个模块当作无关装饰；它们的顺序有含义。
